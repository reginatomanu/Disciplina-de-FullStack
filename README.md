# Fullstack: Códigos das Aulas

Repositório com os códigos das aulas da disciplina de Fullstack.

## Tecnologias

- JavaScript / React.js
- Node.js / Express
- MongoDB
- AJAX, Fetch, JSON, REST

## Conteúdo por mês

- **Agosto:** Revisão de JavaScript, AJAX
- **Setembro:** XMLHttpRequest e Fetch, React.js, Node.js, Express e MongoDB
- **Outubro/Novembro:** Web Services, JSON, REST e Escalabilidade
- **Dezembro:** Exame e encerramento

## Como rodar

\`\`\`bash
npm install
npm start
